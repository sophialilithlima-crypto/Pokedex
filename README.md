# Pokedéx

## 📌Sobre
É uma Pokedéx interativa que permite pesquisar pokemon, visualizar informações, ver suas evoluções, favoritar espécies e explorar a Pokédex de forma prática e organizada através de uma interface inspirada nos jogos da franquia.

## 🎯Objetivo

Criar uma Pokédex simples e interativa para facilitar a busca e a visualização de informações sobre os Pokémon, permitindo explorar espécies, evoluções, estatísticas e favoritos de forma rápida e organizada.
