# Pokedex

Uma Pokédex moderna inspirada no universo Pokémon, desenvolvida com HTML, CSS e JavaScript utilizando a PokéAPI. O projeto possui busca dinâmica entre mais de 1000 Pokémon, sistema de evoluções, modal interativo, carregamento inteligente e interface inspirada nas Pokédex dos jogos.

O design foi feito de uma maneira que siga o layout e cores dos jogos originais, utilizando as cores de acordo com os tipos de pokemons, modal interativo e navegação otimizada. trazendo assim, nostalgia e uma melhor experiência.

# Tecnologias Utilizadas
HTML5, CSS3, JavaScript, PokéAPI e Font Awesome
